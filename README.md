# FourSeas 四季

Minecraft26.1.2 NeoForge 四季模组：季节染色、天气、与日历联动。

## 参考

本模组在实现思路上参考了 [Ecliptic Seasons](https://github.com/TeamTeaMC/Ecliptic-Seasons)（neoforge-26.1 分支），
在此感谢原作者。本仓库代码为独立实现，并非该项目的分支或再分发。

## 依赖

- NeoForge（对应游戏版本）
- LunaClock（日历，必须安装）

## 功能

- 春夏秋冬草叶变色
- 冬天雨变雪、非冬天加速化雪
- 与 LunaClock 天数同步

## 指令

- `/setday <天数>` 设置日历天数
- `/getday` 查看本季第几天
